# EXTENDED ROCK PAPAER SCISSORS

This is an nature-themed extended multi-round rock paper scissors game against the computer where achieving new levels brings new challenges designed for narrow-screen mobile device. 

HOW TO PLAY 
Start off level 1 with the basic rock paper scissors game, get 5 wins and move to level 2 where you get more options. Click the help button to see the instructions and learn how to use your new options. Get 10 wins in level and move to level 3 where you get a new rule which you must follow. Get 15 wins to move to level 4 and unlock the power move. get 20 points in level 4 to end the game. See the winner, your game history and new high score at game over. You could use the quit button to return to splash page and the history button to see your history at any time. 

TECHNOLOGIES USED 
- HTML
- CSS
- JAVASCRIPT
- LocalStorage

WHY THIS PROJECT MATTERS
It combines JavaScript game logic, DOM manipulation, canvas animations, event handling, and local storage into a complete browser-based application.
